# Tecnologías del proyecto — Andjelica Braids Studio

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML5 + CSS3 | Estructurar semánticamente y maquetar con estilos personalizados el sitio web sin depender de gestores de contenido pesados. |
| Versionado | Git y GitHub | Controlar las versiones del proyecto, documentar el historial de cambios mediante commits continuos y alojar el repositorio en la nube. |
| Publicación | GitHub Pages | Desplegar y publicar el sitio web de manera pública, gratuita y accesible en línea para evaluación y uso. |
| Diseño UX/UI | Whimsical | Crear wireframes, moodboards, calco de componentes y diagramas de flujo de usuario (user flows). |
| Prototipado | Google Stitch | Generar y afinar el prototipo visual interactivo en alta fidelidad a partir de las especificaciones de diseño. |
| Asistencia IA | Antigravity AI / Claude | Asistir en la redacción estructurada de requerimientos, especificaciones técnicas y refinamiento del diseño. |
| Editor | Visual Studio Code / Antigravity IDE | Entorno de desarrollo para edición de documentos Markdown, hojas de estilo CSS y maquetación HTML. |

## Integraciones para una versión real

- **Pasarela de pago online:** Integración con Webpay Plus o Mercado Pago para permitir pagos de productos y cobro de abonos/señas de reservas.
- **Sistema de agenda online:** Integración con plataformas como Calendly o Fresha para sincronización automática del calendario de citas y confirmaciones automáticas por SMS/Email.
- **Plataforma de logística y envíos:** Integración con Shipit o Starken API para cotización y generación de etiquetas de despacho en tiempo real.
- **Email Marketing:** Herramienta como Mailchimp o Klaviyo para la entrega automática del lead magnet (guía de cuidados) y correos de fidelización.

## Restricciones

- **Plazo:** Proyecto a desarrollar en tres fases evaluativas entre el 29 de septiembre y el 14 de octubre.
- **Identidad de marca:** La identidad visual, paleta cromática y tipografías se formalizarán en la Fase 2 en base a un estilo moderno, cálido y enfocado en la estética afro/urbana.
- **Dispositivos y enfoque Mobile-First:** El diseño debe priorizar dispositivos móviles (smartphones) ya que el 85% del público objetivo accede desde Instagram/TikTok a través del celular, garantizando adaptabilidad completa en tablets y pantallas de escritorio.
